# Learning Value Criteria

## 总判断原则

一个值得优先处理的视频，至少要满足以下三点中的两点：
1. 能学到方法
2. 能学到流程
3. 能迁移到自己的项目或 skill 设计中

## 高学习价值视频的特征

- 有明确问题（不是泛泛而谈）
- 有清晰步骤（讲"怎么做"）
- 有结构（有框架、不是散讲）
- 有实操演示（实战案例、系统搭建、工具调用）
- 有迁移价值（能用到自己的项目里）
- 有可复用的方法（不是一次性技巧）

## 评分维度

每个候选视频从以下维度判断：

1. **问题清晰度** — 它到底在解决什么问题？
2. **方法密度** — 里面有没有明确方法？
3. **流程清晰度** — 是不是讲清了步骤？
4. **可迁移性** — 是否能迁移到自己的工作和项目？
5. **可实操性** — 是不是看完就能动手试？
6. **可沉淀性** — 是否值得做成学习笔记/skill/workflow/项目方案

## 学习优先级分层

| 级别 | 含义 | 特征 |
|---|---|---|
| **S** | 强烈优先 | 有明确问题、完整步骤、框架、案例、演示、可迁移、可实操 |
| **A** | 优先处理 | 有方法、有结构，对学习有明显帮助 |
| **B** | 可补充 | 有一定启发，补认知和视角 |
| **C** | 低优先 | 有热度但学习价值一般 |
| **D** | 淘汰 | 对学习帮助很弱，热点/盘点/观点/娱乐 |

## 推荐判断句

- 看完之后，我能学到一套什么方法？
- 里面有没有我今天就能试的动作？
- 这个视频是让我"知道了"，还是让我"会做了"？
- 它能不能迁移到我的项目里？
- 它值不值得我沉淀成一个 skill 或模板？
