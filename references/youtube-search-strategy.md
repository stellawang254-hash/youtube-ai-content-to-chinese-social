# YouTube Search Strategy

## 搜索总目标

1. **第一目标：学习** — 优先筛选可学习、可实操、可迁移、可落地的内容
2. **第二目标：发文** — 在满足学习价值的前提下，再判断是否适合改写

## 搜索总原则

1. 主题要收窄，不要泛抓 AI 视频
2. 学习价值优先于热度
3. 实操价值优先于概念热闹
4. 互动验证作为加分项，不是唯一标准
5. 发文价值放在后面判断
6. 新鲜度是可切换的控制项

## 新鲜度搜索策略

### classic 模式
第一轮：AI Agent, Workflow, Automation, LangGraph, LangChain, Tool calling, Memory/reflection, Task orchestration
第二轮：Prompt engineering, Structured output, Long context, Consistency framework, System prompt design
第三轮：AI tools, Productivity tools

### recent 模式
第一轮：主题词 + latest/recent/this month/2026/current best practices
第二轮：+ tutorial/step by step/implementation/practical/workflow
第三轮：+ advanced tips/tool updates/new releases/best practices

### hybrid 模式
先按 recent 搜一轮，再按 classic 补一轮，结果分成：
- 最近时间窗口内最值得学的内容
- 经典补充内容

## 搜索词使用逻辑

- 想学"怎么做"：tutorial, step by step, from scratch, build, implementation
- 想学"怎么落地"：workflow, automation, orchestration, pipeline, practical
- 想补"方法论"：best practices, framework, prompting, consistency, reasoning
- 想补"发文素材"：advanced tips, best tools, comparison, roundup
- 想抓"近一个月"：latest, recent, this month, current, 2026, new update

## 降权处理的内容

- 泛 AI 新闻、纯热点评论、情绪型观点视频
- 没有实操的工具盘点、纯概念讲解
- 只展示结果不讲过程的视频
- 标题很强但内容空的视频
- recent 模式下明显超出时间窗口的内容
